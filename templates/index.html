About Project

This is a voice-first accessibility application for visually impaired users. It includes currency detection, fake note analysis, multiple note counting, history, voice secure access, chatbot support, settings and emergency assistance.

AI Upgrade Roadmap

For production-level accuracy, train YOLOv8 or YOLOv11 on a balanced Indian currency dataset with front, back, old, new, angled, folded, wrinkled and low-light samples. Track precision, recall, F1 score, confusion matrix, loss graph and accuracy graph before replacing the current model file. See docs/AI_MODEL_PLAN.md for dataset sources and the training pipeline.
